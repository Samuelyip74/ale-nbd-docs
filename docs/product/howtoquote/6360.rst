OmniSwitch 6360 Ordering Guide
=================================

.. contents::
   :local:
   :depth: 2

Audience & Outcomes
-------------------
**Audience:** Presales engineers, solution consultants, and channel partners.

**Outcomes:** By the end of this guide you will be able to:

- Select the right products and licenses for a customer use case.
- Produce a complete and supportable Bill of Materials (BOM).


Prerequisites
-------------
- Understanding of customer requirements and constraints.
- Familiarity with networking concepts (switching, PoE, stacking).
- Basic knowledge of licensing models and support services.
- Access to current **price list**, **discount policy**, and **SKU catalog** (MyPortal).

.. _quote-checklist:

Quote Checklist
---------------
- [ ] Select the appropriate model based on the customer requirements (Ports/Uplink Speed, PoE Budget, Transceivers).
- [ ] Select the appropriate power supplies (AC/DC, Redundant).
- [ ] Add required accessories (Rack mount kits, Power Cords, SFPs).
- [ ] Add software licenses, if necessary
- [ ] Add support contract (Partner Support / Support Plus).
- [ ] Add Cloud Management License (OmniVista Cirrus)


OmniSwitch 6360 Product Selection
------------------
Use this section to translate requirements into the right product mix.

**Inputs to collect**

- Users Port: Speed / PoE / Count per switch.
- Uplink: Speed / Type (fiber/copper) / Count per switch.
- Power Supplies: AC or DC / Redundant or not.
- Stacking: Number of switches per stack / Stack bandwidth.
- Accessories: Power cords / Rack mount kits / SFPs.

Frequently Asked Questions (FAQ)
--------------------------------
**Q: How do I co-term licenses when adding devices mid-term?**  
A: Prorate to the master end date; use add-on SKUs where available.

**Q: Do I need optics spares?**  
A: Yes—carry ~10% spares per optic type per site.

**Q: Who approves Strategic band discounts?**  
A: Follow the :ref:`approval-matrix` for thresholds and sign-offs.
