Overview
--------

The Alcatel-Lucent Enterprise OmniSwitch 6570M Stackable Gigabit and Multi-Gigabit Ethernet
LAN switch family provides high performance and scalability with a broad range of interface
types and PoE capabilities, making it ideal for enterprise edge, aggregation, and small data
center deployments.

The switches offer high-density multi-gigabit access with 1G, 2.5G, 5G, and 10G ports, and
uplinks up to 25G and 100G. They deliver advanced Layer 2 and Layer 3 switching, low latency,
and comprehensive security features.

Key features include:
- High-density Multi-Gigabit access
- Non-blocking switching capacity
- PoE++ (up to 90W) on access ports
- Hot-swappable, modular power supplies and fan trays
- Stackable up to eight units
- Front-to-back and back-to-front airflow options


Models
------

**OS6570M-12/12D**

  • 8 ports RJ45 port non-PoE 10/100/1000 Base-T with 2x100/1G Base-X SFP and 2x1G/10G SFP+ ports
  • Primary internal AC/DC power supply with optional external AC/DC backup power supply
  • Optimised ½ x 1RU form factor with optional mounting offerings
  • Fan-less design with 0 to 50° C operating temperature
  • Metro Ethernet Service features included for service provider deployments
  • IEEE 802.1AE MACsec encryption**


**OS6570M-U28X/U28XD**

  • 20x100/1000 Base-X SFP ports, 4xSFP/RJ45 1G combo, 4x1G/10G* SFP+ ports and 2x1G/10G SFP+
  uplink/VLF ports
  • Modular primary AC/DC power supply with optional modular AC/DC backup power supply
  • Supports additional 4x10 GigE uplink/VFL ports with the OS6570-SW-PERF4* license
  • Fan-design with 0 to 50° C operating temperature
  • 1RU x rack width form factor
  • Metro Ethernet Service features included for service provider deployments
  • IEEE 1588v2 (PTP) Transparent Clock** and IEEE 802.1AE MACsec encryption**

**Q: Does the OmniSwitch 6570 support MACSec?**  

A: Yes. The hardware supports IEEE 802.1AE MACSec encryption on all access and uplink ports, however, the software is not ready for MACSec deployment.

Please contact your Alcatel-Lucent Enterprise representative for availability details.

**Q: How do I enable full OSPF routing?** 

A: Install the **OS6570M-SW-AR** Advanced Routing license to enable extended OSPFv2/v3 scalability and routing features.

**Q: Can the OmniSwitch 6560 be managed via OmniVista Cirrus cloud?**  

A: Yes. Use **OVCX-65-BAS** (Base) or **OVCX-65-BIZ** (Business) licenses for secure cloud-based management and analytics.
